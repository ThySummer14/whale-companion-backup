# Minecraft 原创蓝图

`.schem` 文件使用 Minecraft Java 1.21.1 的 Sponge v3 格式，可导入 Axiom 或 WorldEdit。完整源稿和色板保存在各作品目录，方便后续编辑或转换。

| 作品 | 宽 × 高 × 深 | 可编辑原稿 | Minecraft 图纸 |
| --- | --- | --- | --- |
| 潮汐观星门 | 65 × 40 × 33 | [体素 JSON](tidal-stargate/star-gate.voxels.json) | [Sponge](tidal-stargate/star-gate.schem) |
| 潮灯港 | 28 × 41 × 48 | [MagicaVoxel](north-quay/north-quay.vox) | [Sponge](north-quay/north-quay.schem) |
| 潮阙港 | 224 × 93 × 216 | [MagicaVoxel](tidegate/tidegate.vox) | [原版](tidegate/tidegate.schem) · [灯座修正版](tidegate/tidegate-coopcraft.schem) |
| 潮生 · TIDEBORN | 239 × 124 × 199 | [MagicaVoxel](tideborn/tideborn.vox) | [Sponge](tideborn/tideborn.schem) |

图纸以各自的局部原点导出。在 Axiom 中通过 **File → Import Schematic** 导入，用放置预览确认方向、高度和空气方块的处理，再粘贴到世界里。
