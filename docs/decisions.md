| D-066 | 缓存删除必须人工确认并逐项复核真实文件，保留删除墓碑 | 防止越界、符号链接、已变化文件和保护素材被误删，同时让实际释放空间可审计 | `0.14.0` schema v11 与 delete-verified 清理已实现；后台自动清理仍关闭，实机存储验收待进行 |
| D-067 | 手机图片使用受控上传与媒体 ID 引用，不把 Base64 注入 Session | 控制上下文、存储和访问权限，保证附件可审计、可读取和可验证 | `0.15.0` schema v12 动态附件已实现；限制 PNG/JPEG/WebP、10MB 与真实魔数，真机相册显示待验收 |
