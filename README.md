# DSH Companion Bot（暂定名）

一个长期运行在 Mac mini 上、以 DeepSeek Harness（dsh）为 Agent 运行时的个人数字角色。用户通过手机 App 与她聊天、查看和回复动态；角色拥有稳定人设、可管理的长期记忆，并逐步获得语音、虚拟形象、视频通话、Minecraft、视频浏览和歌唱等能力。

> Mac mini 正式运行 Companion `v0.15.1`。DSH Go 安卓版 `0.1.0` 已在 Android 模拟器通过同一 Tailscale 连接验收配对、流式聊天、图片动态和图片回复。受限合成与营地建造、分段语音和其他能力的验证范围见 [开发路线](docs/roadmap.md)。

## 当前已实现

- 单一 `dsh-companion-bot` bundle，包含宿主插件、浏览器面板和共享 API 类型。
- DSH 侧栏 Companion 工作台：总览、场景、活动、中央记忆、任务、能力和角色设置。
- 一个角色同时绑定多个根 Session：聊天、游戏、任务和话题分别使用独立上下文，并按长期 `contextId` 管理。
- 场景换绑新 Session 后，历史活动和中央记忆仍按原 `contextId` 归属；一个 DSH Session 只能归属一个场景。
- 从真实 `session/event` 采集各场景 turn、助手回复、工具调用元数据和 token 用量，不复制聊天正文或工具参数。
- 中央记忆独立于 Session，保存类型、共享/场景私有范围、重要度、置信度、来源、召回次数、长期锚点和完整修订历史。
- 记忆分为候选、活跃、归档和遗忘。归档或遗忘的内容退出日常召回，原文、来源和修订保留。归档可恢复到原来的候选或活跃状态。
- 四个受控记忆工具：`companion_memory_search / remember / correct / forget`，只允许已注册场景的 Session 调用，场景私有记忆不能跨场景修改。
- 每个新用户轮次只注入真实输入命中的记忆与少量长期锚点，单次召回最多 4 条、总预算 3000 字符，不 replay 整个历史 Session。
- 插件自有 SQLite schema v44，保存角色档案、多场景绑定、活动、任务、中央记忆、自我笔记、设备、动态、媒体清单、自主任务、目标级游戏经验和 B 站候选回执。
- 角色内核：持久自主队列、延迟与执行租约、重试和重启恢复；聊天结束后异步整理候选记忆，不让分析任务阻塞当前回复。
- 自我笔记最多 40 条有效角色观察，引文带原消息及发言角色。角色可以凭新证据接续旧笔记，主人反馈独立保留修订。跨场景只带简短的行为倾向。 [角色自我笔记](docs/dsh-integration.md#75-companion-0470-角色自我笔记)
- 自主节律：总开关、记忆整理延迟、自主动态最小间隔与免打扰均可配置；自主动态默认关闭，工作台“自主节律”页显示真实队列与最近决策。
- Minecraft 经历分享候选：角色可以从真实游戏回执中选择是否发动态。由工作台自主节律开启，来源任务保存在动态中，发帖事实也进入共享记忆。 [使用与验证](docs/dsh-integration.md#51-companion-0230-minecraft-经历自主分享)
- Minecraft 营地补给候选：主人可在工作台为一个营地区域授权 15 分钟，大肥鱼根据真实库存选择补充一批木板或放弃。合成回执通过后写入共享记忆。 [营地补给](docs/dsh-integration.md#52-companion-0240-限时营地补给)
- Minecraft 自主搭建候选：主人可改为授权一次 3×3 营地搭建。材料齐备时，大肥鱼决定搭建或保留材料，完成后把实际放置和扣料回执关联到共享记忆。 [自主搭建](docs/dsh-integration.md#53-companion-0250-授权自主搭建)
- Minecraft 多步营地候选：已有工作台时，可授权大肥鱼从背包内备料并搭建。宿主每步核对真实库存，保留两根同种原木，最多合成两批。确认过的步骤可单独追溯。 [备料并搭建](docs/dsh-integration.md#54-companion-0260-授权备料并搭建)
- 用户发帖／评论触发独立线程回应任务，角色可以回复或沉默；同线程去重、冷却、免打扰、暂停与真实回执生效，回应和自主发帖使用不同开关。
- 工具索引在 Agent 创建／恢复 setup 中限制 Companion 工具可见性：普通聊天／游戏使用记忆工具与受限形象动作，动态线程只使用动态工具，记忆整理不注入这些工具。
- 媒体清单核对真实文件、SHA-256、类型、来源、大小、最近使用时间与保留策略；预览后可由主人确认逐项核验删除，模型、原素材、记忆与备份不进入自动清理。
- 私有 Live2D 舞台支持标准模型加载、自然待机、脸红和抬手示意；动作通过真实舞台心跳下发，完成或取消以实际回执为准，不开放任意模型参数写入。
- 小家在工作台和安卓端共用一个活动视图。大肥鱼随游戏动作、舞台播放、聊天和免打扰状态移动到对应位置，最近活动只展示已确认的事件类型和时间。 [小家说明](docs/dsh-integration.md#55-companion-0270-与-android-0110-小家)
- 小家街区在网页和安卓按同一份宿主状态点亮对应建筑。营地联络站展示已确认的自主补给、搭建和勘察回执。 [街区与营地日记](docs/dsh-integration.md#73-companion-0450-与-android-0180-街区活动和营地日记)
- B 站工作台可按 BV 号或视频链接查阅公开资料及可用字幕片段。大肥鱼在独立浏览会话使用同一个有预算的只读连接器，实际读到的字幕会留下一条小家活动。 [B 站与聊天附件](docs/dsh-integration.md#56-companion-0280-与-android-0120-聊天附件和-b-站浏览)

- 允许自主动态后，大肥鱼可以自行决定是否分享一次有回执的营地勘察。主人可另行允许宿主随动态附上路线示意图，网页和配对手机复用已有图片动态。 [勘察图文动态](docs/dsh-integration.md#76-companion-0480-勘察图文动态)
- 通过 `ctx.agents.create/resume()` 创建与恢复场景 Session，并通过 `agentDefaultModel.currentSelection()` 复用宿主默认模型。
- 消息发送、取消、历史读取：`accepted` 只表示入队，`message.completed` 与持久事件才表示完成。
- WebSocket 推送流式文本、助手完成和领域活动；按 `contextId` 与 activity cursor 过滤补发，瞬时不伪造持久化。
- 场景面板可新建专用 Session、恢复离线 Session、绑定现有 Session。
- 任务状态机：`accepted → running → succeeded / failed / cancelled`。
- 本机同源管理 API，覆盖健康检查、多场景、中央记忆、角色、任务、能力和受控活动写入。
- 独立 `/companion-device/api/`：5 分钟一次性配对链接、设备凭据哈希、设备列表与撤销；手机不接触 DSH 启动令牌或模型密钥。
- 撤销设备立即终止其已跟踪 WebSocket，后续认证返回 401；设备列表不返回 `secretHash`。
- 每 10 秒 ping 保活与 25 秒 watchdog，支持半开连接恢复；撤销为订阅终止状态，旧连接回调不会使其重连。
- 真实动态时间线：SQLite 保存文字动态与一层回复，用户可发布、回复和删除自己的内容；角色通过受控 Agent 工具发布，事件通知与断线后的列表对账复用现有连接。
- Mac mini 工作台和手机均可查看动态及回复；角色与手机用户的作者身份分离，不由客户端冒充角色。
- GPT-SoVITS v5 turbo 大肥鱼声线：真实助手消息按需通过独立常驻服务合成，MPS 全精度、单任务队列、1500 字上限、60 秒超时、WAV 缓存和失败重试；任务返回真实执行状态，不自动朗读全部回复。
- 语音只从持久历史中的助手消息生成，媒体文件权限为 600；设备通过鉴权的任务／音频接口访问，不能传入任意文件路径。
- Expo App 包含配对、场景、流式聊天、取消、历史与断线恢复；原生凭据使用 SecureStore。
- 主要界面采用浅色，包含角色中心、图标导航、紧凑聊天输入区、短促原生转场与按压反馈；不把 X 的深色外观当作产品要求。
- 用户指定的 `whale.mp4` 在角色区静音循环播放，小头像使用 `whale.png`；播放器离屏与后台暂停，减少动态效果时使用静态帧。素材仅进入手机 App，不进入 DSH 插件包。
- 已通过：构建、tarball 安装、旧库迁移、双 Session 工具写入、跨场景召回、流式回复、取消、历史、WebSocket 回放、离线恢复和设备 API。原生与恢复验收结果见接入文档。

## 核心思路

- **一个角色核心**：聊天、动态、游戏和媒体行为共享同一套人设、中央记忆与状态。
- **Session 只是执行上下文**：场景是长期身份，Session 是场景当前的工作台，不把角色绑死在某个对话日志上。
- **单包但分层**：`core` 不导入 DSH，`host` 负责宿主适配，`client` 负责面板，`protocol` 共享类型；手机 App 在 workspace 中独立交付。
- **Cortico＋Coopanion 是总纲参照**：以真实游玩、语音、直播和角色行动为产品目标，复用事件节律、World 分层、形象与受控动作机制，不把演示当成本项目进度。
- **AIRI 提供 Live2D 与部分场景机制参考**：按场景保存持久 Session、后台任务独立、记忆索引加单条事实、遗忘保留 tombstone，不作为唯一总纲。
- **superagent 提供工程原则**：事件、授权、任务状态、单一数据权威和管理工作台。
- **Tobs / Hermes 提供上下文预算原则**：少量核心锚点，详细记忆按需检索，不把全部历史塞进提示词。
- **ECHO / SurfCore 提供记忆纪律**：来源可追踪、活跃记忆与历史修订分开、场景隐私边界与遗忘机制。
- **Mem0 / Graphiti 作为后续 Provider 候选**：确有语义检索或时间关系需求时再评估，不提前引入向量库、Neo4j 或第二套 Agent。
- **单用户、私网优先**：手机端只通过 Tailscale 访问，不开放公网，不实现多人社交平台。

## 构建与安装

安卓 DSH Go 版源码位于 [apps/dsh-go](apps/dsh-go/)，基于上游 `v1.0.13`，以独立的 `companion` flavor 和 `lib/whale_main.dart` 启动。配对时在 Mac mini 工作台的“设备”页填写 Tailscale HTTPS 地址，再将一次性链接粘贴到 App。图片动态需要 Companion `0.15.0+`，纯图片动态与回复需要 `0.15.1+`。

DSH Go 安卓版 `0.2.0` 在已完成的助手消息下提供“听语音”。点按后复用 Mac mini 的按需 TTS，播放时可以暂停、继续或在结束后重播。APK 与 `0.1.0` 使用同一签名，可覆盖安装。 [Android ARM64 APK](whale-companion-go-0.2.0-arm64.apk)

安卓 `0.3.0` 新增状态栏和状态页，可查看角色连接、语音、Minecraft、虚拟形象以及已记录的 Token。使用正式 Companion `0.15.1` 的现有接口。 [Android 0.3.0 ARM64 APK](whale-companion-go-0.3.0-arm64.apk)

安卓 `0.4.0` 新增活动页，通过已配对主机的记录查看动态回应、Minecraft 动作和舞台回执。动态活动可打开对应原帖或回复。 [Android 0.4.0 ARM64 APK](whale-companion-go-0.4.0-arm64.apk)

安卓 `0.5.0` 的“听语音”支持边收边播。连接已配置 PCM Provider 的 Companion `0.18.0` 时优先使用实时流，旧主机或起播前的可回退错误沿用 WAV。播放、暂停、继续与切页停止由原生音频状态确认。 [Android 0.5.0 ARM64 APK](whale-companion-go-0.5.0-arm64.apk)

安卓 `0.6.0` 加入点按录音。连接已配置本地转写的 Companion `0.19.0` 后，录音最多 15 秒，停止时由配对主机转写。结果追加到输入草稿，编辑确认后发送，回复可用“听语音”播放。 [Android 0.6.0 ARM64 APK](whale-companion-go-0.6.0-arm64.apk)

安卓 `0.7.0` 在检测到说话后的停顿时自动结束录音并转写。搭配 Companion `0.20.0`，可在确认语音草稿时选择朗读这次回复，等待中和播放中均可停止。 [Android 0.7.0 ARM64 APK](whale-companion-go-0.7.0-arm64.apk)

安卓 `0.8.0` 搭配配置了流式 TTS 的 Companion `0.21.0`，在勾选朗读的回合中提前准备首句音频。回复完成、写入持久层且首句一致时复用音频。状态页可查看最近一次 PCM 到达和原生起播耗时。 [Android 0.8.0 ARM64 APK](whale-companion-go-0.8.0-arm64.apk)

## 本地语音

当前默认 Provider 是 **GPT-SoVITS v5 turbo**，使用用户本地二创工程中已有的大肥鱼参考声线，不再以 Piper 作为正式声线。独立运行环境位于 `~/.local/share/companion/gsv/`，不修改原二创工程，不进入系统 Python，也不把模型权重塞进 DSH tarball。

- `api.py` 常驻于 `127.0.0.1:9881`，使用 MPS、全精度和 v5 turbo；不经过 Tailscale 暴露，也不允许手机调用其模型管理接口。
- 固定参考音频为 `~/.local/share/companion/gsv/voice/deepseek_ref_b_7s.wav`，配套文本来自已有声线元数据。部署文件的输入读取采用 `soundfile` 回退，不要求额外安装 TorchCodec。
- Companion 配置 `ttsProvider=gpt-sovits`、`ttsEndpoint=http://127.0.0.1:9881/`；`ttsReferenceAudio` 可用绝对路径覆盖默认声线。`ttsPythonPath` 与 `ttsModelPath` 仅保留给旧的 Piper 技术验证。
- 模型服务通过 `/companion-health` 报告就绪状态。Companion 负责固定声线、请求队列、真实任务状态、60 秒超时、WAV 校验与缓存；首次合成需要等待，后续复用同一消息与声线的缓存。
- Drama3 是后续高表现力 Provider 候选，尚未在本项目部署；其运行方式与 Mac mini 资源限制见 `docs/references.md`。

助手消息下方点击“听语音”才会合成，不自动朗读所有回复。设备接口为：

- `POST /companion-device/api/messages/:messageId/tts`，JSON 为 `{ "contextId": "chat.mobile" }`；也可通过 `POST /companion-device/api/tts` 同时传入 `contextId` 与 `messageId`。
- `GET /companion-device/api/tts/:taskId` 返回真实的 `accepted / running / succeeded / failed / cancelled` 状态。
- `GET /companion-device/api/tts/:taskId/audio` 返回带设备鉴权的 WAV，支持 Range；手机使用 `expo-audio` 的鉴权请求头播放。

文本必须来自该场景持久历史中的真实助手消息，单条最多 1500 字。同一时刻最多一个合成任务，等待队列有界；同一消息和声线复用缓存，失败可以重试。WAV 位于 `$DSH_HOME/companion/media/voice/`，文件权限为 600，接口不接受任意文件路径。

### 低延迟舞台语音（v0.17.0 候选）

舞台启用声音后，“播放最近回复”和按场景开启的自动朗读可边接收 PCM 边播放。PCM 从已完成的真实助手回复合成，只在内存中经过宿主和舞台。点击舞台的“停止语音”会立即停止本地播放，并中断宿主到引擎的流。工作台会显示本次播放使用 PCM 或 WAV，也可直接选择“用 WAV 播放”。手机语音消息仍使用上面的 WAV 缓存和 Range 接口。

`ttsStreamEndpoint` 默认为空，沿用 WAV。启用本机 VoxWeft 时，将预热且已载入命名声线的服务绑定在 loopback，Companion 配置示例如下。模型选型、预热步骤和实测口径见 [低延迟语音验收](docs/dsh-integration.md#44-v0170-低延迟-tts-候选)。

```yaml
ttsStreamProtocol: voxweft
ttsStreamEndpoint: http://127.0.0.1:18133/generate
ttsStreamVoice: deepseek-whale-voxcpm2
ttsStreamSampleRate: 48000
```

### Android 本地语音输入（v0.19.0 候选）

将 [本机 ASR 启动器](scripts/run-mlx-asr.py) 指向本地 Qwen3-ASR MLX 模型，再为 Companion 设置 `asrEndpoint: http://127.0.0.1:18135/transcribe`。录音只送到配对的 Companion 主机，由该主机上的 loopback 服务转写。模型预热、计时和验收条件见 [语音输入验收](docs/dsh-integration.md#46-android-060-与-companion-0190-本地语音输入)。

- `data/model-profile.json`：由该模型生成的参数、物理所有权和动作目录，不拿其他模型的配置混用。
- `vendor/live2dcubismcore.min.js`：从 [Live2D 官方 SDK](https://www.live2d.com/en/sdk/download/web/) 单独取得并遵循其许可；当前校验的 SHA-256 为 `25ae938cb4fe282ce189b357bcc97e603d1e1f7ec78bf04150d401c23cdc792f`。
- 舞台支持脸红、抬手示意、点头和摇头。动作由宿主任务下发给指定舞台，浏览器实际执行后回传起播和完成。断线或超时取消任务。
- 舞台可根据小家的实时活动改变头部与视线。页面中可关闭情境姿态，系统减少动态效果设置也会停用此层。
- 桌面管理舞台和手机观看页各自在同源范围读取指定的模型资源。文字聊天独立于形象渲染，舞台从实际播放音频驱动口型。手机观看页使用独立的短期授权。

## 手机 App 开发

```sh
pnpm --filter @companion/mobile typecheck
pnpm --filter @companion/mobile exec expo run:ios --device <模拟器-UDID>
pnpm --filter @companion/mobile start
```

首次运行会生成 `apps/mobile/ios` 并安装 Pods；日常开发保持 `start` 运行。Xcode 27 使用 **Device Hub**，不再提供旧的 `Simulator.app`。项目内的 React Native 补丁仅修复 CocoaPods 对非 ASCII 路径的编码处理，已纳入 pnpm lockfile。`expo-device-hub` 仅作本机开发面板，不进入 DSH 包，也不应对网络开放。

### Android（优先验收平台）

需要 Java、Android SDK、`adb` 和一台模拟器或真机。以下为本次 Homebrew SDK 的路径示例；已有 Android Studio 时，将 `ANDROID_HOME` 改为实际 SDK 路径即可，不需要重装。

```sh
export JAVA_HOME="$(/usr/libexec/java_home -v21)"
export ANDROID_HOME=/opt/homebrew/share/android-commandlinetools
export ANDROID_SDK_ROOT="$ANDROID_HOME"
export PATH="$ANDROID_HOME/platform-tools:$PATH"
pnpm --filter @companion/mobile exec expo run:android --device emulator-5554
pnpm --filter @companion/mobile start
```

`emulator-5554` 可替换为 `adb devices` 显示的实际设备。仅本地 debug 可用 `adb reverse` 将模拟器的回环端口转发到 Mac；生产连接使用 Tailscale HTTPS，不把 `10.0.2.2` 或明文 HTTP 当作正式方案。

## Tailscale 私网接入

先由 tailnet 管理员在 Tailscale 后台启用 Serve，再查看现有配置；不要重置其他服务：

```sh
tailscale serve status
tailscale serve --bg 8787
tailscale serve status
```

将状态给出的 `https://<mac-mini>.<tailnet>.ts.net` 填入设备配对链接。只使用 Serve，不使用 Funnel。当前 Serve 已转发到 Companion 的 `127.0.0.1:18788`，真实安卓配对、HTTPS/WSS 和聊天已通过；新版语音播放仍需在手机上复验。

DSH 仍只监听 `127.0.0.1`，由 Serve 转发 HTTPS 和 WebSocket。Companion 管理接口拒绝非本机 Host；DSH 自带接口仍受宿主自身认证保护，不要把启动令牌交给手机。若以后要远程管理工作台，应单独设计管理认证，而不是放开同源检查。

## 数据与备份

数据默认在 `$DSH_HOME/companion/companion.db`；如设置了 `dataDir`，以实际配置为准。设备凭据只以哈希存入数据库，恢复数据库不会暴露原明文。配对码只在内存中有效，宿主重启后需要重新生成。

停止共用这些目录的 DSH 写入服务后，使用 `node scripts/companion-backup.mjs` 创建快照。工具保存 SQLite 一致性副本、DSH 会话和附件、Companion 媒体、Minecraft 事件游标及当前安装包。恢复时校验文件和数据库，写到新 Home。旧语音 WAV 随文件移到新路径时，只更新恢复副本里的对应记录。模型、虚拟环境、启动凭据和私有配置由宿主独立保管。 [备份、校验与恢复命令](docs/dsh-integration.md#85-离线升级与回退演练)

Mac mini 的插件安装包保留在 `~/.local/share/companion/packages/`。DSH 包管理器会保留 tarball 路径引用，不要在安装后删除仍被引用的旧包，也不要把会被清理的 `/tmp` 当作长期安装来源。

移除插件但保留领域数据：

```sh
dsh plugin --profile companion remove dsh-companion-bot
```

详细恢复命令与实测结果见 [dsh 接入说明](docs/dsh-integration.md)。
